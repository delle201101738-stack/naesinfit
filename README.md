# 내신핏 리뷰테스트 (영어 II · 천재 강상구 · 1과)

학생이 링크로 접속해 파트별 리뷰테스트를 보고, 결과가 선생님 대시보드에 자동으로 모입니다.

- 학생용 : `https://내주소.vercel.app`
- 선생님용 : `https://내주소.vercel.app/teacher`

---

## 배포 방법 (터미널 없이, 브라우저만으로)

### 1단계 · GitHub에 파일 올리기

1. <https://github.com> 가입 후 로그인
2. 오른쪽 위 **+** → **New repository**
3. Repository name 에 `naesinfit` 입력 → **Private** 선택 → **Create repository**
4. 다음 화면에서 **uploading an existing file** 클릭
5. 압축을 푼 파일 **전부**를 드래그해서 올립니다
   (`index.html`, `teacher.html`, `package.json`, `vercel.json`, `README.md`, 그리고 `api` 폴더)
   - 압축을 풀면 파일들이 바로 나옵니다. 그대로 전부 끌어다 놓으면 됩니다
6. 맨 아래 **Commit changes** 클릭

### 2단계 · Vercel에 연결하기

1. <https://vercel.com> 접속 → **Continue with GitHub** 로 가입
2. **Add New… → Project**
3. 방금 만든 `naesinfit` 저장소 옆 **Import** 클릭
4. 아무것도 건드리지 말고 **Deploy** 클릭 (1분쯤 걸립니다)
5. 완료되면 `https://naesinfit-xxxx.vercel.app` 주소가 나옵니다

> 이 시점에는 아직 결과가 저장되지 않습니다. 3단계까지 마쳐야 합니다.

### 3단계 · 결과 저장소(데이터베이스) 붙이기

1. Vercel 프로젝트 화면에서 위쪽 **Storage** 탭
2. **Create Database** → **Neon** (Serverless Postgres) 선택
3. 무료 플랜(Free)으로 **Create** → **Connect**
4. 자동으로 연결되고 접속 주소가 프로젝트에 등록됩니다

### 4단계 · 선생님 비밀번호 정하기

1. **Settings** 탭 → 왼쪽 **Environment Variables**
2. Key 에 `TEACHER_PIN`, Value 에 원하는 비밀번호(예: `hazel2026`) 입력 → **Save**
3. **Deployments** 탭 → 맨 위 배포의 **⋯** → **Redeploy** 클릭

### 5단계 · 확인

- 학생용 주소를 폰에서 열어 이름을 넣고 한 파트 풀어 보세요
- `/teacher` 주소에서 비밀번호를 넣으면 방금 그 결과가 보입니다

## 학생에게 안내할 것

> 링크 열고 **이름만** 쓰면 바로 시작합니다.
> 이름은 출석부에 있는 이름 그대로 써 주세요. (동명이인이면 `김지민B` 처럼)
> 인터넷이 끊겨도 문제는 풀립니다. 다시 연결되면 결과가 자동으로 전송돼요.

## 선생님 대시보드에서 보는 것

| 항목 | 내용 |
|---|---|
| 한눈에 보기 | 응시 학생 수, 총 응시, 평균 정답률, 오늘 응시 |
| 학생별 | 정답률 낮은 순 정렬, 진행한 파트 수, 이름 클릭 시 응시 내역 |
| 파트별 평균 | 어느 파트가 약한지 (보강 우선순위) |
| 많이 틀린 문항 | 오답률 순 · 학생들이 실제로 쓴 오답과 정답 |
| 최근 응시 | 응시별 오답 전체 보기 |
| CSV 내려받기 | 엑셀로 열어 성적표에 붙이기 |

## 다음 과·다른 교재를 추가하려면

문항 데이터는 `index.html` 안 `const C = { ... }` 한 덩어리에 들어 있습니다.
같은 형식(JSON)으로 만들어 그 부분만 바꾸면 앱 코드는 손대지 않아도 됩니다.

```
vocab / gram : 지문 + 각 빈칸의 두 선택지와 정답
fix          : 지문 + (A)~(K) 구간별 정답 여부와 고칠 말
tf           : 지문 + 문장별 T/F
order        : 주어진 글 + (A)(B)(C) + 정답 순서
insert       : 삽입할 문장 + 지문 + 정답 위치
write        : 우리말 + 영작 정답 (★중요 문장만)
read         : 본문 영한 대조
```
